# TimeSink「精修 · Refined」后端同步清单

设计依据：[用户提供的完整设计稿](https://claude.ai/artifact/XPWfaofcbb8RNGDABCjmmK)，本地原稿 `docs/reference/refined/design.html`。日期：2026-09-28。

这里的“后端”包括 Mac 本地采集、数据库、系统服务和云端 API。界面由真实数据驱动；设计稿里的时长、账号、设备数、截图数量和版本号不作为产品事实写入。

状态：**已实现**＝当前工作区有实际读写路径；**已有/保留**＝复用现有能力；**待补齐**＝仍需开发；**待实机验收**＝有实现，但隔离测试不能确认系统或外部服务效果。本次没有部署云端、修改账号或删除个人数据。已安装并重启界面复刻版本；其后合入的上游改动尚未重新安装。
