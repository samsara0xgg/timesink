# 时间空间预览

这是独立的 macOS 原型，用于先查看本机截图的空间回看效果，尚未集成 TimeSink 主 App。沿用现有预览的深色背景、系统字体、橙色选中提示和轻量控件，让真实时间与截图主体成为主要内容。

## 运行

需要 macOS 14 或更新版本、Swift 6 工具链，以及 TimeSink 已采集的今日记录。在项目根目录运行：

```sh
bash scripts/run_time_space.sh
```

脚本默认以 Release 配置构建 `TimeSinkSpace`（需要调试时可设置 `SPACE_CONFIGURATION=debug`），生成并本地签名 `.build/TimeSinkSpace.app`，随后打开窗口。仅检查构建可运行 `swift build --product TimeSinkSpace`。

## 数据与分组

预览以只读方式打开 `~/Library/Application Support/TimeSink/timesink.sqlite` 的 `capture` 表，图片来自同目录的 `captures/`。它不启动采集器、不运行数据库迁移，也不写回记录或改写原始截图。

“今天”按系统当前时区计算，只读取采集时间落在今日的记录；结束时间最多保留到今日结束。相邻记录仅在 app bundle ID、window ID、窗口标题相同，且当前采集时间距上一张的 `lastSeenAt` 不超过 75 秒时，合为一段。标题去除首尾空白，空标题使用应用名。当前内置名单中的受保护窗口会中断分组并被跳过，超过 75 秒的空档也会另起一段；相同窗口的不同访问不会无条件合并。

## 回看方式

1. **空间**：截图卡片按记录顺序排列；滚动或拖动画布穿行，停止后吸附到最近的一段，点击卡片进入过程。下方时间条按真实起止时间定位，空档保留；点击空档会选择距离最近的一段。
2. **过程**：点击“回看过程”，用信息栏滑块查看同一段内的变化；点击快照张数按钮按需展开缩略图浮层。缩略图尺寸为 220 × 138 点，使用最长边 480 像素的预览。时间显示为本地 24 小时制，快照精确到秒。
3. **完整原图**：点击“完整原图”打开保存的完整截图，适应窗口并保持原比例，不裁掉图像主体。空间卡片是带应用、标题和时间标注的预览图；原图页直接读取原始文件，两者外观不同，文件本身未被改写。原图页仍按窗口适配，没有新增捏合缩放。预览不做 OCR 或 AI 摘要。

画布随窗口尺寸调整取景，标题栏、信息栏和时间条分别占 36、54、36 点，不再另设页脚。空间和过程支持触控板双指向内捏合缩小、向外展开放大，范围为 **50%–100%**，默认 **80%**；标题栏的减号、加号每次调整 10 个百分点，点击百分比恢复 80%。到达上下限后对应按钮禁用。进入过程或切换记忆保留当前缩放比例；缩放只改变相机距离，不改变记忆或快照选择。100% 表示当前窗口能容纳的最大取景尺寸，不表示原图像素 1:1 显示。

| 操作 | 效果 |
| --- | --- |
| 左右方向键／信息栏箭头 | 切换记忆段；完整原图中切换当前段的快照 |
| 触控板双指捏合／标题栏 −、+ | 在空间或过程中缩放切片，限制在 50%–100% |
| 标题栏百分比 | 恢复默认 80% |
| 空格 | 进入过程；画布获得焦点时可切换空间与过程 |
| 上下方向键（画布获得焦点时） | 切换当前段的快照 |
| Return | 打开当前快照的完整原图 |
| Esc／返回按钮 | 退出原图，或从过程返回空间 |
| 快照滑块／快照张数按钮 | 按快照顺序切换／展开快照浮层；不足两张时滑块禁用 |

启动时缺失或不可读的图片不参与快照切换，活动段仍保留；没有可用图片时显示占位提示并禁用“完整原图”。打开原图时若文件已被清理或加载失败，原图页显示不可用提示。今日无数据或数据库无法读取时显示说明；先在 TimeSink 采集画面，再重新打开预览。Metal 无法初始化时，仍可用下方时间条和按钮查看记录及原图。

## 当前范围

今日数据只在启动时读取一次；查看新增记录或跨日后需关闭并重新打开。分类仅按应用名、窗口标题的简单规则区分开发、浏览、文档、对话与其他活动。“记忆段”目前是连续窗口活动的分组，并非真正的语义记忆聚合。此预览没有历史日期选择、实时刷新或原图自由缩放功能。

已验证构建与启动、原图内方向键切换及时间同步、Esc 返回同一记忆段。临时数据夹具检查覆盖分组、日界、缺图、路径边界、只读、24 小时制与时间条区间命中；这些检查不代表性能基准或主 App 集成验收。

本次扩展通过 Release 构建与临时缩放状态检查，覆盖默认值、上下限、反复触及边界、重置，以及保持位置、快照与过程状态。运行中的辅助功能树已确认 83% 显示和 100% 时加号禁用；当前自动化工具不支持捏合手势，真实触控板捏合未完成自动化实测。

## 性能处理

卡片图片解码、缩放和文字绘制由最多两个后台任务执行；主线程只上传已准备好的卡片像素并读取纹理缓存。当前选中的快照及其相邻快照预取宽 1600 像素的卡片，邻近记忆额外预取宽 1200 像素的卡片，远处使用宽 600 像素的卡片；尚未准备好高分辨率纹理时可先使用已有的较低分辨率。完整原图不受预览分辨率影响。Metal 纹理缓存仍按 LRU 淘汰，预算为 96 MiB。动画由屏幕同步的 CADisplayLink 驱动，稳定后停止；细小滚动由原生画布处理，跨活动边界时才刷新 SwiftUI 元数据。

以下为此前 **1200 像素卡片版本**的历史隔离测试：本机同一组 50 张截图，原来单卡主线程准备中位数 22.11 ms、p95 31.00 ms；后台处理后，主线程上传中位数 0.56 ms、p95 0.62 ms。14 张已缓存纹理的读取 p95 为 0.036 ms。该测量仅覆盖当时的图片准备和缓存路径，未测量本次 1600 像素卡片版本，也不等同于端到端帧率保证。
